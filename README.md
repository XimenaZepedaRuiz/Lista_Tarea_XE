# Lista de Tareas XE

## Descripción

Nuestro mini-proyecto consiste en desarrollar una aplicación de lista de tareas que permita a los usuarios organizar y dar seguimiento a sus actividades pendientes de manera sencilla. Elegimos este proyecto porque su alcance es adecuado para nuestro nivel actual de conocimientos y nos permite aplicar las fases del proceso de Ingeniería de Software.

## User Stories

- Como usuario, quiero agregar una tarea para registrar una actividad pendiente.
- Como usuario, quiero visualizar mis tareas para conocer las actividades que tengo pendientes.
- Como usuario, quiero marcar una tarea como completada para identificar las actividades que ya realicé.
- Como usuario, quiero eliminar una tarea para quitar actividades que ya no necesito.
- Como usuario, quiero limpiar las tareas completadas para mantener organizada mi lista.

## Metodología

### Kanban

Elegimos trabajar con un enfoque ágil utilizando Kanban porque somos un equipo pequeño y contamos con un tiempo limitado para desarrollar el mini-proyecto. El tablero nos permitirá dividir el trabajo en tareas pequeñas, visualizar el avance y mover las actividades entre pendiente, en proceso y terminado.
