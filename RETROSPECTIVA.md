# Retrospectiva - Lista de Tareas XE

## ¿Qué hicimos bien?

- Se logró organizar el trabajo mediante la metodología Kanban.
- Se dividió el proyecto en tareas pequeñas utilizando Issues.
- Se trabajó de manera colaborativa utilizando Git y GitHub.
- Se utilizó un Pull Request para integrar los cambios realizados.
- Se realizaron pruebas para comprobar el funcionamiento de la aplicación.
- Se logró implementar las funciones principales de la lista de tareas.

## ¿Qué podemos mejorar?

- Mejorar la planificación y distribución del tiempo durante el desarrollo.
- Mantener una comunicación constante entre los integrantes del equipo.
- Realizar pruebas desde etapas más tempranas del desarrollo.
- Mejorar la organización de las tareas antes de comenzar cada cambio.
- Documentar con mayor detalle los cambios realizados durante el proyecto.

## ¿Qué aprendimos?

- Aprendimos a utilizar Git y GitHub para trabajar de manera colaborativa.
- Aprendimos a crear y gestionar Issues y Pull Requests.
- Aprendimos a utilizar un tablero Kanban para organizar las actividades.
- Reforzamos nuestros conocimientos de HTML, CSS y JavaScript.
- Comprendimos mejor el flujo de trabajo de un proyecto de Ingeniería de Software.

## Conclusión

El desarrollo de la Lista de Tareas XE permitió aplicar conceptos de Ingeniería de Software mediante un proyecto práctico. El uso de Kanban, Issues, ramas, commits y Pull Requests permitió organizar el trabajo y llevar un seguimiento del avance del proyecto.

Como equipo, consideramos que se cumplieron los objetivos principales del proyecto y que el desarrollo nos permitió adquirir experiencia en el uso de herramientas de control de versiones y metodologías ágiles.
